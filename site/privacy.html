隐私政策

本隐私政策说明 IDN Technology Group Inc. 在提供 IDN Code 网站、桌面端和相关账号服务时如何处理信息。

生效日期：2026 年 10 月 5 日

我们收集的信息

我们可能收集账号邮箱、登录状态、设备标识、下载候补邮箱、服务使用记录、用户主动提交的任务内容，以及为提供服务所需的技术日志。

信息用途

这些信息用于提供账号登录、下载通知、服务安全、产品功能、故障排查、用户支持和合规所需的记录保存。

本地执行与权限

IDN Code 的桌面任务在用户授权的本地电脑环境中执行。项目文件、浏览器、应用和系统权限由用户在本机控制；除用户主动提交的内容外，本地代码与文件不会被上传托管。

数据共享

我们不会出售个人信息。仅在提供服务、遵守法律、保护用户和服务安全，或经用户明确授权时，与必要的服务处理方共享有限信息。

模型通道与第三方处理

使用 IDN 官方算力通道时，请求由 IDN 或其服务处理方处理；配置自带兼容 API Key 时，相关请求由你选择的服务方按其规则处理，请同时阅读该服务方的隐私政策。

用户选择

用户可以选择不提交下载候补邮箱，也可以通过账号入口管理登录状态、设备连接和可用服务配置。

数据安全

我们采用合理的技术和组织措施保护信息，但任何互联网或本地软件系统都无法保证绝对安全。

联系我们

如需查询、更新或删除相关信息，可通过 support@idncode.com 或 IDN Technology Group Inc. 官方支持渠道联系我们。
